RENITA PORTFOLIO
- Masukkan foto Renita ke assets/images/renita-photo.jpg
- Buka index.html di browser.
- Klik project untuk melihat preview lebih besar.
- Tambahkan project di array `projects` pada js/script.js.
- Salin format data project yang sudah ada, lalu isi title, description, year, dan image.
- Simpan gambar project di assets/images/ lalu isi image, misalnya: 'assets/images/project-baru.jpg'.
- Biarkan image kosong ('') jika ingin memakai preview ilustrasi.
- Untuk artwork, gunakan 'food', 'formula', atau 'travel'; boleh kosong untuk preview umum.
- Ganti your-email@example.com di js/script.js dan index.html.
- Ganti tautan # untuk Instagram, TikTok, dan GitHub.
